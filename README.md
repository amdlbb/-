## 项目简介
一个基于SpringBoot+Vue的前后端分离电商平台，专注于书籍销售场景。包含完整的用户系统、商品展示、订单管理等模块。

## 技术栈
### 后端
- **框架**: Spring Boot
- **持久层**: MyBatis-Plus
- **数据库**: MySQL
- **构建工具**: Maven
- **其他**: Lombok + Session管理

### 前端
- **框架**: Vue + Element
- **路由**: Vue Router
- **Http库**：axios
- **构建工具**: Webpack 

## 功能特性
### 核心模块
- 用户注册与登录（Session）
- 商品操作（对商品增删改，按价格区间与名称查询）
- 商品分类浏览（三级菜单导航，可伸缩菜单栏）
- 热销榜单（Fire组件动态标识爆款）
- 购物车与订单系统（含取消订单功能）
- 个人中心（头像上传/资料修改）

### 特色实现
- 响应式商品展示（支持滚动加载）
- 组件高度复用（HotSale/CategorySearch）
- 动态路由
- 销量实时同步机制
- 文件上传（商品图片，用户头像）
- CSS关键帧动画（NavNav+）
